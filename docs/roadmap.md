# Roadmap

What we build next, in order. This file is the source of truth for progress, one line per plan.

## How to use this file

- `prioritise-roadmap` writes this file with the person who runs it.
- `plan-feature` turns a line with no plan into one or more plans.
- `start-plan` takes the first ready plan from the top. `node .factory/scripts/next.mjs` shows what is ready, blocked and in flight.
- `build-plan` ticks the line's box in its landing commit, and a plan's landing commit sets its `status` to merged.

Add your first line under the section below. The whole process is in [.factory/docs/process.md](../.factory/docs/process.md).
